Split PDF

Pull out the pages you need, or break a PDF into several smaller files. Your file stays on your device.

How to split a PDF

  1. Choose your PDF. The page count appears.
  2. Pick a mode: extract ranges into one PDF, split every N pages, or save each page separately. The last two give you a ZIP file.
  3. For ranges, type pages such as 1-3, 5, 8-10. For every N pages, type the number.
  4. Click Split & download.

Page numbers start at 1. If a range goes beyond the last page you will see an error and nothing is downloaded.
