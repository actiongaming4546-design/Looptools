PDF → Text

Pull the text out of a PDF so you can copy it or save it as a .txt file. Your file stays on your device.

How to extract text from a PDF

  1. Choose a PDF.
  2. Click Extract text. Each page is labelled in the result.
  3. Copy the text, or download it as a .txt file.

This reads text that is already stored in the PDF. Scanned documents and photos of pages contain only images, so this tool cannot read them and will tell you when it finds no text. Layout, columns and tables are not preserved.
