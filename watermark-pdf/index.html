Watermark & Page Numbers

Add a diagonal text watermark and number your pages, without uploading the document.

How to watermark a PDF

  1. Choose a PDF.
  2. Set the watermark text, size, opacity, rotation and position (center, top or bottom). Clear the text if you only want page numbers.
  3. Optional: add numbers like 1, 2, 3, “Page 1 of N”, or Bates numbers with your own prefix, such as DOC-000001.
  4. Click Apply & download.

The tool uses a standard font, so watermark text supports Latin letters and numbers only. A watermark is a visual mark added to the page, not a security feature.
