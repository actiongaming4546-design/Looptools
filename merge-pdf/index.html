Merge PDF

Combine several PDF files into one document. Everything happens in your browser, so your files are not uploaded.

How to merge PDF files

  1. Add two or more PDFs by choosing them or dragging them in.
  2. Drag the rows to put the files in the order you want.
  3. Optional: type pages such as 1-3, 5 in a file’s box to include only those pages. Leave it empty for all pages.
  4. Click Merge & download.

Password-protected PDFs cannot be opened by this tool, so remove the password first. Very large files use a lot of memory in your browser, so merge them in smaller batches if the page slows down.
